2. 本部署包运行时为 Linux x64。若服务器不是 x86_64，更换为对应架构的 Node 24。
3. 将 donghan-website.zip 上传到服务器临时目录，解压并进入根目录。恢复可执行权限：
   chmod +x runtime/bin/node deploy/install.sh
4. 已有自有域名则用实际域名；暂未提供自有域名，可使用临时 Host donghan.159-75-67-132.sslip.io，DNS 指向 159.75.67.132。该临时地址未在目标服务器安装验证。
5. 确认 8010 未被占用后执行：
   sudo bash deploy/install.sh donghan.159-75-67-132.sslip.io 8010
   上述域名和端口可按实际情况调整。脚本保留现有默认站点，仅创建 donghan 的独立 Host 路由。
6. 网站目录 /var/www/donghan；数据目录 /var/lib/donghan；服务 donghan.service。

8. 对外实际访问源必须与 systemd 的 PUBLIC_URL 一致。改 HTTPS 时也更新 PUBLIC_URL 并重启服务。
